# 玄学出海 · 商业机会调研（2026-11，开源版）

一份用一堂「商业预判」体系一轮一轮做出来的调研：从 77 个备选方向，到 4 个候选，到一套零成本的线上测试方案。**所有判断都带证据和信度标记，所有结论都写明是案头调研级别，没有一个真实客户被验证过。**

## 方法论

调研顺序严格按一堂的体系走，不跳步：商业预判（充分做加法 → 专业做减法）、投资人大哉 9 问、AB 模型与行业画布六判断点、集中度方法（相关市场 → CRn → 四象限）、OSCAR 调研五部曲。方法论本身属于一堂，本仓库只有在使用它们时的最简要转述，不含课程内容。

## 证据怎么标

✅ 可核实（申报 / 规则原文 / 多源一致）· 🟡 单一来源或只看到搜索摘要 · ⚠️ 当事人自述或营销数字 · ❓ 查过没查到。**本仓库大部分是 🟡**：竞品官网和支付公司原文在调研环境里打不开，Semrush 数字是模型估计，论坛原帖只看到摘要。

- 合伙人与相关业务改为中性称呼；调研者署名 Yixuan。

**Semrush 原始数据保留了**：`工具/semrush/` 下 5 个 CSV 是调研者自己买的试用额度拉的（2026-11-05～08），一并开源。
