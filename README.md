## 二、三种看法，挑一种

### 1. 直接在网页上看（最简单，零安装）

点上面的文件夹，点进任何一个 `.md` 文件，GitHub 会把它排好版显示：表格、标题、链接都能点。**手机也能看。**

### 2. 看成「网站」（最舒服，有目录和搜索）

本仓库每次更新都会自动生成一个阅读网站：**https://yixuanfranco.github.io/xuanxue-chuhai-research/**
左边是目录，右上角能搜全文。读长报告、来回跳章节用这个。仓库刚更新后网站要等 1–2 分钟才跟上，是正常的。

### 3. 下载到自己电脑（想离线看、想用 Obsidian 读）

- **不装任何东西**：仓库首页绿色按钮 **Code → Download ZIP**，解压后用任何能看 Markdown 的软件打开（推荐 [Obsidian](https://obsidian.md/)，免费；把解压出来的文件夹当作一个「库」打开就行）。
- **想以后一键更新**：装 [GitHub Desktop](https://desktop.github.com/)（免费、图形界面）→ File → Clone repository → 填 `YixuanFranco/xuanxue-chuhai-research`。以后点一下 **Fetch origin** 就拿到最新内容，不用重新下载。

## 三、怎么参与（从零开始）

### 第 0 步：注册 GitHub 账号

https://github.com/signup ，免费。用户名以后会显示在你的贡献上，取一个你愿意让同学看到的。

### 第 1 步：先用「议题」（Issues）说话——不用会任何命令

仓库顶部的 **Issues** 标签就是留言板，每一条留言叫一个「议题」。点 **New issue**，会看到三个模板：

| 模板 | 什么时候用 | 例子 |
| --- | --- | --- |
| 🐛 纠错 | 发现数据、链接、判断有错 | 「R1-A 第 35 行 Astrotalk 的海外收入比例，Inc42 原文是 34% 不是 37%」 |
| ❓ 提问 / 讨论 | 看不懂、不同意、想追问 | 「05 里第 23 条划掉的理由我不同意，因为……」 |
| 💡 新方向提议 | 想开一个新的调研文件夹 | 「我想做『跨境母婴用品出海』，计划分三轮……」 |

写议题的规矩只有一条：**说清楚指的是哪个文件的哪一段**。能贴截图更好。

### 第 2 步：想改内容或加内容——两条路

**路 A（推荐给大多数人）：申请成为协作者。** 在 Issues 里发一条「申请加入」，Yixuan 把你加进来后，你就能直接在网页上编辑：点进文件 → 右上角铅笔图标 ✏️ → 改 → 最下面写一句改了什么 → **Commit changes**。新建文件也在网页上点 **Add file** 就行。

**路 B（会一点 Git 的人）：Fork → 改 → Pull Request。** 右上角 **Fork** 复制一份到你名下，改完点 **Contribute → Open pull request**。我们看过后合并。

两条路都不需要装软件。

### 第 3 步：开自己的方向文件夹

照 [`CONTRIBUTING.md`](CONTRIBUTING.md) 里的规范：一个方向一个文件夹，文件夹里先有 `README.md` 和 `PLAN.md`，之后每一轮产出一份编号文件。**规范不长，核心就三条：带证据、标信度、不编。**

## 四、GitHub 的几个东西，用大白话说

| 名词 | 它是什么 | 我们怎么用 |
| --- | --- | --- |
| **Repository（仓库）** | 一个项目的所有文件 + 全部修改历史 | 就是这个页面 |
| **Commit（提交）** | 一次「保存并写一句改了什么」 | 每次改完都写清楚改了什么，别写「更新」 |
| **Issue（议题）** | 一条可以讨论、可以关闭的留言 | 纠错、提问、提议都用它；解决了就 Close |
| **Pull Request（合并请求）** | 「我改了这些，请看一眼再合进去」 | 路 B 用；改别人负责的文件夹时也建议走这个 |
| **Milestone（里程碑）** | 把一批议题打包成一个阶段目标，带截止日和进度条 | 每个方向的每一轮调研开一个里程碑，如「玄学出海 · R7 线上测试」；相关议题挂上去，完成度一眼看见 |
| **Label（标签）** | 给议题贴的颜色标 | 用方向名（`玄学出海`）+ 类型（`纠错` / `提问` / `新方向`） |
| **Discussions（讨论区）** | 比议题更松的聊天版 | 闲聊、分享资料、问「这个方向值不值得做」 |
| **Watch / Star** | 关注 / 收藏 | 点 **Watch → All activity** 就能收到新议题和更新的邮件 |
| **Wiki** | 仓库自带的一个小百科 | 我们**不把调研放 Wiki**（会和仓库里的文件变成两份、慢慢对不上）；Wiki 只放新手问答 |

## 五、读调研时的三个约定

1. **证据信度符号**，全库通用：✅ 可核实（公司申报、规则原文、多个独立来源一致）· 🟡 单一来源或只看到搜索摘要 · ⚠️ 当事人自述或营销数字 · ❓ 查过没查到。**看到 🟡 和 ⚠️ 别当成事实。**
2. **效果数字都是自述**：「月入万刀」「利润率 98%」这类数字一律标 ⚠️，不拿来做推算。
3. **不编**：查不到就写「未查到」。这比写一个看起来合理的数字值钱得多。
