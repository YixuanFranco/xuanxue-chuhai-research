## 一句话摘要

**真正被第三方数字验证「做大了」的只有三类：
- 真人撮合（Astrotalk / InstaAstro，印度，已到亿美元级）、订阅 App（Nebula / CHANI / The Pattern，见 F1-c）、以及卡牌实物（Kickstarter 塔罗单项目 $140 万）；

其余方向——Etsy 解读、YouTube/TikTok 塔罗、Substack、认证课、水晶订阅盒、宠物通灵、灵修 retreat、命理约会——全是「个体户量级」（年入几万到几十万美元），而且收入多为自述。

**对我们最关键的两个发现**

① **东方命理 API 没有正规厂商**——Prokerala / AstrologyAPI.com 只做吠陀 + 西占，八字 API 只有 Apify 上几个个人上传的 actor（$2–20/千次）；
② **英文东方命理的「产品化 + 实物」已经有人在做但都很小**——Etsy 八字解读店评价数个位到几十、「按八字配水晶手串」有 LunarBeads、Qi Yi Crystal、SixCats 等，均无规模信号；
**唯一有体量的东方命理出海玩家仍是 Joey Yap（自述 37 国、70 万学员，第三方估营收 $5–20M）这类「大师 IP + 学院 + 出版」老派打法**。 🟡
