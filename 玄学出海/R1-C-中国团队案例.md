## 二、每个案例要点（对 / 坑）

### C1 FateTell —— 唯一有经营数字的中国团队 AI 命理出海样本

- **对**：先上网页、跑通付费再做 App（2024 年底网页 → 2026 年初 App），绕开了 App Store 对算命类的 4.3 拒审（见 C8），也就是 Web2App 的「先 web 收钱」顺序。
- **对**：定位从「算命」改成「自我认知 / wellness」——PH 页写的是 wellness AI for self-discovery、「更像人格模型而不是算命玩具」，和 糊站验尸 里「合规风险最高的死法是信任与合规」对得上。
- **对**：高价单次报告（$19.99–39.99）+ 订阅组合，而非 $0.5 试读钩子；据转述客单 >$60。⚠️
- **坑 / 存疑**：「利润率接近 98%」「复购 38.7%」均为公司口径经媒体转述；「注册 2 万 + 付费约 2 万」几乎等于 100% 付费率，口径明显有问题。**不能作为单位经济的输入。** ⚠️
- **坑**：PH 只有约 104 关注，说明英文社区声量很小；行业文章（woshipm）判断「通用大模型免费可用」是这类出海派的最大威胁。🟡

### C2 Timing（顺时）

- **对**：创始人本身在美国生活，以「能量 / 效率」包装东方玄学，避开「fortune telling」字眼。
- **缺**：没有任何用户、营收、融资数据。只能当「存在这种定位」的例子。🟡

### C3 东海水晶 —— 中国在玄学出海里最确定的一块规模

- **对**：真正的规模在**实物供应链**，不是 App。外语主播 24 小时直播 + 阿里国际站 B2B 两条腿；欧美偏好水晶球、雕件、晶簇。✅ 存在 / 🟡 数字
- **对**：有卖家把水晶和风水、命理结合做定制，TikTok 做「消磁教学」类互动内容——但该文案例来源不明。⚠️
- **坑**：SCMP（2025）报道全球消费下行，本地商家觉得「行业失去光泽」、海外客户收缩；NBC 引英国买家称 TikTok 水晶市场「饱和、没那么好玩了」；虎嗅称美国直播转化冷淡、文化差异大。🟡
- **坑**：官方营收数字三个来源三个口径（交易额 400 亿+ / 营收 460 亿 / 线上 320 亿），不能直接拿来算市场份额。

### C4 塔罗 / Oracle 卡代工

- **对**：欧美独立塔罗品牌、Kickstarter 项目的印刷大量落在广东和香港；MPC 是创作者圈常用的按需印刷。✅（WOPC 名录）
- **对**：厂商主动做英文 SEO 内容（xkdisplay 写「Tarot Cards Manufacturer in China: OEM & ODM」系列）抢 B2B 询盘——说明这个词有 2B 需求。🟡
- **缺**：无营收、起订量、价格的可信数据；全部是厂商营销页。⚠️

### C5 Joey Yap —— 华人英文命理 IP 的天花板样本

- **对**：用英文讲八字 / 风水，产品是「书 + 课 + 认证 + 咨询 + 排盘工具」的全链条，学员覆盖 30+ 国；**卖的是培养从业者（认证），不只是给 C 端算命**。🟡
- **坑 / 缺**：没有营收数字；不是中国大陆团队，是马来西亚华人，起家依托东南亚华人市场，可迁移性要打折。

### C6 国内中文命理 App 挂海外区

- **事实**：大量国内命理 App 直接上架港区、美区，宣传「为全球华人打造」。❓
- **判断（非证据）**：只是 App Store 全球分发的副产品，没看到针对海外华人的本地化投放或数据；天时子平页面评分数为 0。

### C7 TikTok 直播 MCN

- **事实**：中国 MCN 被字节拉去培训海外主播，佣金 10%–30%，主播拿打赏 50%；业内人称「海外直播落后国内三四年」。🟡（2021–2023 年报道，偏旧）
- **缺**：**塔罗 / 占卜直播的中国 MCN 一个案例都没查到**——这一条在 #30、#35 上仍是空白。
